Aurora Student Suite — Complete Project

Landing website and Admin Panel are included in the same project folder.

Landing pages: Home, About, Students, Attendance, Programs, Insights, Contact, Login, Register.
Admin pages: Dashboard, Students, Add Student, Update Student.

Login flow: use the landing Login page; successful login opens admin/index.html. Admin pages require the browser login flag. Logout clears it.

Stack: HTML5, CSS3, Bootstrap 5, Bootstrap Icons, JavaScript, localStorage.
